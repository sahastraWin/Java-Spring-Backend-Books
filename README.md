## 🌟 Why This Repository?

<img align="right" width="270" src="https://media.giphy.com/media/SWoSkN6DxTszqIKEqv/giphy.gif" alt="Coding"/>

Backend development with Java & Spring is one of the **most in-demand skill sets** in the industry. But the ecosystem is vast — Spring Boot, Spring Security, Spring Data, Spring Integration, Microservices — knowing *what to learn and in what order* is half the battle.

This repository solves that with a **5-phase progression** from day one to production-grade distributed systems.

| ✅ Feature | 💡 Detail |
|---|---|
| 🗺️ 5-Phase Roadmap | Structured from fundamentals to microservices architecture |
| 🏭 Production-Grade | Covers security, enterprise patterns, and cloud-native design |
| 📦 Git LFS Ready | Large PDFs stored and served seamlessly |
| 🎯 Industry-Aligned | Mirrors real-world Spring Boot project lifecycle |
| 🆓 Free to Use | All resources compiled for learners |

## 📂 Book Collection

### 🟩 Phase 1 — Core Spring & Boot Fundamentals
> *Start here. Learn the Spring ecosystem from first principles.*

| # | Book | Why Read It |
|---|------|-------------|
| 1 | **Spring Start Here** | The most beginner-friendly Spring book available — learn by doing |
| 2 | **Spring Boot in Action** | Rapid application development, auto-config, and production-ready apps |
| 3 | **Spring Framework Documentation** | Official reference — the authoritative source for all Spring concepts |

---

### 🟦 Phase 2 — Web APIs, Data Persistence & Enterprise Layouts
> *Build real APIs, connect to databases, and structure enterprise applications.*

| # | Book | Why Read It |
|---|------|-------------|
| 1 | **Jim Stafford's Enterprise Java Course Notes** | Practical enterprise Java patterns — REST, JPA, layered architecture |
| 2 | **Spring in Action, 5th Edition** | The definitive Spring cookbook — MVC, REST, reactive, and more |
| 3 | **Java Persistence with Spring Data and Hibernate** | Master ORM, JPA, Hibernate, and Spring Data repositories |

---

### 🟧 Phase 3 — Advanced Production Standards & Security
> *Harden your applications. Secure endpoints, handle authorization, and go pro.*

| # | Book | Why Read It |
|---|------|-------------|
| 1 | **Spring Security in Action** | OAuth2, JWT, method security — everything you need to secure Spring apps |
| 2 | **Pro Spring 6** | Deep-dive into the latest Spring internals — AOP, context, advanced DI |
| 3 | **Spring Boot 3 Official Reference Manual** | Official guide for Spring Boot 3 — actuator, native images, observability |

---

### 🟪 Phase 4 — Enterprise System Integration
> *Connect systems, handle events, and build robust integration pipelines.*

| # | Book | Why Read It |
|---|------|-------------|
| 1 | **Spring Integration in Action** | Enterprise Integration Patterns (EIP) with Spring — channels, adapters, gateways |

---

### 🟥 Phase 5 — Distributed Systems & Microservices Architecture
> *Design, build, and deploy cloud-native microservices at scale.*

| # | Book | Why Read It |
|---|------|-------------|
| 1 | **Building Microservices** — Sam Newman | The definitive guide to microservices design patterns and architecture |
| 2 | **Spring Microservices in Action** | Hands-on microservices with Spring Cloud, Eureka, and Zuul |
| 3 | **Microservices Patterns** — Chris Richardson | Saga, CQRS, event sourcing — production-grade distributed system patterns |
| 4 | **Cloud Native Spring in Action** | Kubernetes, Docker, Spring Cloud — modern cloud-native deployment |

## 🤝 Contributing
